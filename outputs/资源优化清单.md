# 1.5.0 移除与保留工序清单

| 工序 | 本次处理 | 影响 |
| --- | --- | --- |
| 投票页每15秒查询 | 删除 | 页面闲置不自动查询；用户点击刷新查看新活动/管理员提前结束状态 |
| 窗口重新获得焦点查询 | 删除 | 切换浏览器窗口不会自动访问数据库 |
| 进入页面、筛选、提交后读取 | 保留并合并同时重复请求 | 保持必要交互与自己的投票选择 |
| 每秒倒计时 | 保留，本地计算 | 不产生每秒数据库查询 |
| 投票详情到期 | 每个活动/截止时间一次刷新 | 截止后读取结果；服务器始终拒绝超时投票 |
| 普通请求的一分钟间隔全局清理 | 删除 | 每个请求不再顺带执行四类清理SQL |
| 冷启动空写事务探测 | 删除 | 健康检查只读；提交时仍检查数据库错误 |
| 每5分钟清理 | 配置改为每日北京时间03:00 | 用户必须修改原云端触发器；代码包不会自动替换定时器 |
| 每次清理范围 | 每类最多100条，4类，无循环 | 积压分天清理，日志给出实际删除数 |
| 投票列表逐项读取选择/保护数据 | 改为批量读取 | 本地20项学生列表只用2次SQL，后台额外保护数据也批量读取 |
| 来信三种状态分别计数 | 改为一次分组统计 | 保持分类及30天过滤语义 |
| 账号与权限、反重复、截止、上传类型与大小校验 | 全部保留 | 不通过删安全检查换取省资源 |
| 已发布/待审附件 | 按引用保留，最后引用移除才回收 | 草稿、退回稿、撤回稿仍可继续编辑；不再需要时删除投稿记录释放其附件 |

物理删除不等于立即减少所有计费：数据库按平台规则计量；附件分块清理有每日批次上限。数据库/附件没有迁移，未更改套餐。不能保证低流量之外的高并发成本。
