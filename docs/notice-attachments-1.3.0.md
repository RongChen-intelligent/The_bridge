# THE BRIDGE 1.3.0 · 验收与清理说明

2026-10-19。代码已通过本地验收，尚未替你部署正式站。

## 修复

通知附件改为 512 KB 二进制分段上传，发布只提交引用。单个文件最大 10 MB、总量 40 MB、最多 8 个附件；投票图片复用同一上传方式。支持 PNG、JPEG、WebP，通知还支持 PDF。图片不压缩。

正文三种对齐与四档字号（16/18/22/28 px）即时应用到编辑框，并保存在发布内容中。上传显示进度，临时故障自动重试，失败保留表单和已完成上传。旧通知附件继续兼容。

## 原因

旧实现把图片 Base64 嵌入 JSON，触发平台文本请求 100 KB 限制。对公开健康路径的无写入探测确认大 JSON 返回 413，512 KB 二进制请求可通过网关进入应用。

参考：[平台大小限制](https://docs.cloudbase.net/error-code/EXCEED_MAX_PAYLOAD_SIZE)、[HTTP 请求与响应](https://docs.cloudbase.net/service/access-cloud-function)。

## 验收结果

- 62 项自动化检查全部通过，包括旧来信、投票、权限、附件大小和总量、顺序与重复分段、定时发布、绑定、删除及过期回收。
- 隔离本地数据库与真实浏览器成功发布两张 PNG（各 3,608,651 字节）和 PDF（1,200,015 字节），超过旧大小限制。本地服务器模拟文本请求 100 KB 限制。
- 发布 JSON 最大 652 字节；二进制请求不超过 524,288 字节。模拟一次网络故障后自动重试成功。
- 学生端图片保留原始 1024×1024 尺寸；PDF 下载重组大小和头部正确。
- 三种对齐、四档字号、预览、发布、再次编辑保留附件均通过浏览器检查。
- 390 px 手机视口无横向溢出；浏览器无 JavaScript 异常。

没有向正式数据库发布测试内容。上传新包后仍需在正式站验收一条含 2–5 MB 图片的通知；步骤见《更新与使用说明》。
