# THE BRIDGE · 验收与清理说明

版本 1.2.0 · 2026-10-18。验证对象为本地构建与独立测试库；没有修改正式网站、生产数据库或工作人员账号。

当前交付包已更新至 1.2.1；本文件保留首次改版的设计、清理和验收记录。来信白屏修复的最新验收见《来信白屏修复说明.md》。

## 完成内容

- 首页依照提供的图片改为白底、海军蓝与矢车菊蓝标题、桥形弧线、本地衬线字体，保留全部指定文案。下方通知、信箱、投票采用不同版式，避免三个重复卡片。
- 学生通知为只读列表与详情；工作人员可编辑排版、附件、草稿、发布时间、已发布内容和删除操作。
- 一个查询码保留全部来信与回复；学生和工作人员均可追加，多次工作人员回复彼此独立，旧记录兼容。
- 投票支持图文选项、最多可选数量、服务器截止、倒计时、自动刷新、结果排行，以及票数/占比显示设置。进行中接口不会向学生返回票数。
- 工作人员入口保持三个主要模块，并保留现有登录、密码与账号管理功能。

## 视觉依据与检查边界

使用了用户指定的 design-taste-frontend、ui-ux-pro-max、impeccable。选用方向为 `type-only-statement`，seed `1490698022`，以用户参考图为首要依据。

保留大写学校与平台名称、品牌弧线和无照片海报风格，因此明确放宽图片数量、眉题和品牌小标识规则。未添加虚构校园照片、视频、活动数字或评价。首页实际消息来自 API；后台不可用或没有内容时会呈现对应状态。

设计自评：设计 7.7 / 易用性 8.0 / 创意 7.0 / 内容 8.0，原始加权分 7.68。按 design-taste-frontend 的通用“至少四张真实图片”规则，设计项封顶 6.5，严格分为 7.20。这不是外部获奖评价；本次优先保持参考图的纯文字与弧线构图。

英文使用 Cormorant Garamond、Manrope，字体文件已随前端打包，运行时无需访问 Google Fonts。两款字体均附 SIL OFL 许可证。中文使用设备本地宋体/无衬线回退，不同系统字形可能略有差别。
